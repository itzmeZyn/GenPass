# Genpass

A local-first password toolkit with a dark, dashboard-style interface inspired by modern creative dashboards.

## Features
- Secure password generation with the Web Crypto API
- Passphrase generator
- PIN generator
- Password analyzer with entropy estimate
- Strong / Maximum / Easy to type / Alphanumeric / Ultra presets
- Batch generation
- Session-only password history (never leaves the device, cleared on tab close)
- Passphrase word-count presets, configurable separator, and optional custom word list
- Quick PIN length presets
- Dark / light mode
- Installable PWA + offline service worker
- Privacy page and custom 404 page
- No account and no password-generation backend

## Privacy
Generation and analysis happen in the browser. Genpass does not intentionally send generated passwords or analyzer input to a server.

## Run
Open `index.html` directly, or deploy the folder to GitHub Pages, Netlify, Cloudflare Pages, or another static host.
